## 1. Il Vocabolario di Base dei Sintomi

Prima di recarti in clinica o in farmacia, devi saper indicare cosa non va. In inglese si usa spesso la parola **Ache** (dolore continuo) unita alla parte del corpo, oppure **Pain** (dolore più acuto).

| Inglese | Italiano |
| :--- | :--- |
| **Headache / Stomachache / Backache** | *Mal di testa / Mal di pancia / Mal di schiena* |
| **Sore throat** | *Mal di gola* |
| **Fever / Temperature** | *Febbre (es. "I have a temperature")* |
| **Dizzy** | *Vertiginoso / Mi gira la testa* |
| **Nauseous / Sick** | *Nauseato* |

## 3. Chiamare i Soccorsi

In caso di emergenza vitale e immediata, i numeri cambiano in base al Paese (911 in USA/Canada, 999 in UK, 112 in Europa/Australia). Tieni a mente queste frasi assolute:

| Inglese | Italiano |
| :--- | :--- |
| **"I need an ambulance."** | *Ho bisogno di un'ambulanza.* |
| **"There’s been an accident."** | *C'è stato un incidente.* |
| **"Someone is having a heart attack."** | *Qualcuno sta avendo un infarto.* |
| **"Someone is unconscious."** | *Qualcuno è svenuto.* |

## Conclusione: La preparazione è la miglior cura

Avere le parole giuste al momento giusto può letteralmente salvare una vacanza. Tuttavia, leggere un dialogo a schermo non garantisce che tu riesca a capirlo quando un medico o un ufficiale di polizia madrelingua ti risponde a velocità normale. Allenati ad ascoltare e a parlare a voce alta prima di salire sull'aereo.
