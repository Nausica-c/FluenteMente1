Quando si viaggia, si spera sempre che vada tutto liscio. Ma un mal di testa feroce, un'intossicazione alimentare o una distorsione alla caviglia possono capitare.

Il problema? Quando non ti senti bene o sei spaventato, l'ansia prende il sopravvento e l'inglese che hai studiato sembra svanire. Spiegare a un farmacista o a un medico esattamente *dove* fa male richiede un lessico specifico che raramente si impara sui libri di scuola.

## 1. Il Vocabolario dei Sintomi

Per ricevere il giusto aiuto, devi saper indicare cosa non va. In inglese si usa spesso la parola **Ache** (dolore continuo) unita alla parte del corpo, oppure **Pain** (dolore più acuto).

### I Malesseri Comuni

| Inglese | Italiano |
| :--- | :--- |
| **Headache / Stomachache / Backache** | *Mal di testa / Mal di pancia / Mal di schiena* |
| **Sore throat** | *Mal di gola* |
| **Fever / Temperature** | *Febbre (es. "I have a temperature")* |
| **Cough** | *Tosse* |
| **Cold / Flu** | *Raffreddore / Influenza* |
| **Food poisoning** | *Intossicazione alimentare* |

### Come ti senti? (Aggettivi)

| Inglese | Italiano |
| :--- | :--- |
| **Dizzy** | *Vertiginoso / Mi gira la testa* |
| **Nauseous** | *Nauseato* |
| **Weak** | *Debole* |
| **Swollen** | *Gonfio (es. per una storta)* |
| **Bleeding** | *Sanguinante* |

## 2. In Farmacia (Pharmacy / Drugstore)

Molti farmaci che in Italia sono da banco, all'estero richiedono la *prescription* (ricetta medica).

### I Prodotti

| Inglese | Italiano |
| :--- | :--- |
| **Painkillers** | *Antidolorifici* |
| **Antibiotics** | *Antibiotici* |
| **Plaster (UK) / Band-aid (USA)** | *Cerotto* |
| **Ointment / Cream** | *Pomata / Crema* |

### Le frasi chiave per il farmacista

| Inglese | Italiano |
| :--- | :--- |
| **"I need something for a headache."** | *Ho bisogno di qualcosa per il mal di testa.* |
| **"Do you have anything for a sore throat?"** | *Ha qualcosa per il mal di gola?* |
| **"Can you suggest an ointment?"** | *Può suggerirmi una pomata?* |
| **"Do I need a prescription for this?"** | *Mi serve la prescrizione medica per questo?* |

---

## 3. Dal Medico e al Pronto Soccorso (ER)

Se la situazione è seria, dovrai farti visitare. Queste frasi ti aiuteranno a rispondere alle domande del dottore (*"Where does it hurt?"*).

| Inglese | Italiano |
| :--- | :--- |
| **"I need to see a doctor."** | *Ho bisogno di vedere un medico.* |
| **"It hurts right here."** | *Mi fa male proprio qui.* |
| **"I have a sharp / dull pain in my chest."** | *Ho un dolore acuto / sordo al petto.* |
| **"I think I’ve sprained my ankle."** | *Credo di essermi slogato la caviglia.* |
| **"I am allergic to penicillin."** | *Sono allergico alla penicillina. (FONDAMENTALE)* |

---

## 4. Chiamare i Soccorsi

In caso di emergenza grave, i numeri cambiano in base al Paese (911 in USA/Canada, 999 in UK, 112 in Europa/Australia).

| Inglese | Italiano |
| :--- | :--- |
| **"I need an ambulance."** | *Ho bisogno di un'ambulanza.* |
| **"There’s been an accident."** | *C'è stato un incidente.* |
| **"Someone is having a heart attack."** | *Qualcuno sta avendo un infarto.* |
| **"Someone is unconscious."** | *Qualcuno è svenuto.* |

## Conclusione: La preparazione è la miglior cura

Avere le parole giuste al momento giusto può letteralmente salvare una vacanza. Tuttavia, leggere un dialogo a schermo non garantisce che tu riesca a capirlo quando un medico o un farmacista madrelingua ti risponde a velocità normale. Allenati ad ascoltare e a parlare a voce alta prima di salire sull'aereo.
