Ti è mai capitato di tornare in hotel e accorgerti che quel vestito comprato con entusiasmo è troppo grande, o che l'oggetto scelto non ti convince del tutto? Chiedere un cambio o un reso all'estero può intimidire, ma con le frasi giuste diventa un'operazione rapida e priva di stress.

Ricorda sempre di tenere a portata di mano lo scontrino (*receipt*), perché è l'unico documento che garantisce i tuoi diritti di consumatore.

## 1. Vocabolario Essenziale

Termini fondamentali da conoscere per interagire correttamente con il personale del negozio quando un articolo non ti soddisfa.

| Inglese | Italiano |
| :--- | :--- |
| **Return** | *Restituzione* |
| **Exchange** | *Cambio* |
| **Refund** | *Rimborso* |
| **Policy** | *Politica (es. di reso)* |
| **Receipt** | *Scontrino* |

---

## 2. Frasi per il Reso

Usa queste espressioni per informarti sulla politica del negozio o per avviare una pratica di cambio o rimborso.

| Inglese | Italiano |
| :--- | :--- |
| **"Can I return this item?"** | *Posso restituire questo articolo?* |
| **"Can I exchange it for a different size?"** | *Posso cambiarlo con una taglia diversa?* |
| **"What is your return policy?"** | *Qual è la vostra politica sui resi?* |
| **"I would like a refund, please."** | *Vorrei un rimborso, per favore.* |
