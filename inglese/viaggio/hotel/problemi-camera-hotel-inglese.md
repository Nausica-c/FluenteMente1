Scoprire che l'aria condizionata non funziona o che mancano gli asciugamani dopo una lunga giornata di esplorazione può essere frustrante. 

Segnalare un problema alla reception è fondamentale per goderti il tuo soggiorno. Non serve fare lunghe lamentele o conoscere terminologie tecniche: basta usare poche frasi chiare ed educate per ottenere subito l'assistenza necessaria.

## 1. Vocabolario Essenziale

Ecco i termini base per identificare i servizi dell'hotel, il personale e gli oggetti presenti in stanza.

| Inglese | Italiano |
| :--- | :--- |
| **Housekeeping** | *Servizio ai piani / Pulizie* |
| **Maintenance** | *Manutenzione* |
| **Towels** | *Asciugamani* |

| **Air conditioning (AC) / Heating** | *Aria condizionata / Riscaldamento* |

| **Noisy** | *Rumoroso* |

## 2. Chiamare la Reception

Usa queste frasi per segnalare un guasto tecnico, un disservizio o per richiedere materiale aggiuntivo direttamente dalla cornetta della tua stanza.

| Inglese | Italiano |
| :--- | :--- |
| **"The air conditioning isn't working."** | *L'aria condizionata non funziona.* |
| **"Could we have some extra towels, please?"** | *Potremmo avere degli asciugamani extra, per favore?* |
| **"There is no hot water in the shower."** | *Non c'è acqua calda nella doccia.* |
| **"The room is very noisy. Can I change rooms?"** | *La camera è molto rumorosa. Posso cambiare stanza?* |
| **"The TV is broken."** | *La televisione è rotta.* |
