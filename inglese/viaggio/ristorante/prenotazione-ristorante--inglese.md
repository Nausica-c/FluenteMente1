Mangiare fuori è una delle esperienze più piacevoli di ogni viaggio, ma arrivare in un locale affollato senza sapere come chiedere un tavolo o confermare una prenotazione può creare un po' di stress.

La buona notizia è che le interazioni all'ingresso del ristorante sono estremamente standardizzate. Con poche frasi chiave, potrai gestire l'accoglienza, scegliere il posto perfetto e dare il via alla tua serata senza incomprensioni.

## 1. Vocabolario Essenziale

Questi sono i termini principali che sentirai utilizzare dal personale di sala o che userai per definire le tue necessità.

| Inglese | Italiano |
| :--- | :--- |
| **Reservation / Booking** | *Prenotazione* |
| **Table for two** | *Tavolo per due* |
| **Inside / Outside terrace** | *Interno / Terrazza esterna* |
| **Waitstaff / Waiter / Waitress** | *Personale di sala / Cameriere / Cameriera* |
| **Menu** | *Menu* |

---

## 2. Frasi Utili all'Arrivo

Usa queste espressioni per gestire l'ingresso al locale, che tu abbia già prenotato o che tu sia alla ricerca di un posto libero.

| Inglese | Italiano |
| :--- | :--- |
| **"I have a reservation for two at 8 PM."** | *Ho una prenotazione per due alle 20:00.* |
| **"Do you have a table for four?"** | *Avete un tavolo per quattro?* |
| **"Could we sit outside, please?"** | *Possiamo sederci fuori, per favore?* |
| **"Could we see the menu, please?"** | *Possiamo vedere il menu?* |

---
