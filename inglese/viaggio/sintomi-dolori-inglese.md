Quando non stai bene, limitarsi a dire *"I feel bad"* (Sto male) non aiuta il medico o il farmacista a darti la cura giusta. Per ricevere assistenza rapida ed efficace, devi saper isolare il problema: devi saper indicare **dove** ti fa male, **che tipo** di dolore provi e quali sono i tuoi sintomi esatti.

In questo articolo abbiamo espanso il vocabolario di base per coprire tutti i malesseri più comuni che possono rovinare una vacanza, dai problemi intestinali alle reazioni allergiche.

<div class="in-breve-box in-breve-viaggio">
  <strong>💡 La regola di Ache vs Pain:</strong> In inglese, <strong>Ache</strong> si usa per un dolore sordo e continuo (spesso unito alla parte del corpo, come <em>Headache</em> o <em>Backache</em>). <strong>Pain</strong> si usa invece per descrivere un dolore improvviso, acuto e più difficile da ignorare (es. <em>"I have a pain in my chest"</em>).
</div>

## 1. Le Parti del Corpo (Body Parts)

Se non conosci il nome esatto della malattia, il primo passo per farti capire è indicare la parte del corpo interessata.

| Inglese | Italiano |
| :--- | :--- |
| **Chest** | *Petto / Torace* |
| **Stomach / Belly** | *Stomaco / Pancia* |
| **Back** | *Schiena* |
| **Neck / Throat** | *Collo / Gola* |
| **Ankle** | *Caviglia* |
| **Knee** | *Ginocchio* |
| **Skin** | *Pelle* |

## 2. I Sintomi da Viaggio (Travel Symptoms)

Le intossicazioni alimentari, i colpi di sole o le punture di insetto sono tra i nemici principali dei viaggiatori. Ecco come chiamarli.

| Inglese | Italiano |
| :--- | :--- |
| **Food poisoning** | *Intossicazione alimentare* |
| **Diarrhea / Upset stomach** | *Diarrea / Stomaco sottosopra* |
| **Vomiting / Throwing up** | *Vomito / Vomitare* |
| **Sunburn** | *Scottatura solare* |
| **Insect bite** | *Puntura d'insetto* |
| **Rash** | *Sfogo cutaneo / Eruzione* |
| **Allergic reaction** | *Reazione allergica* |
| **Shortness of breath** | *Mancanza di respiro (Fame d'aria)* |

---

## 3. Descrivere il Malessere (Aggettivi e Sensazioni)

Il dolore non è tutto uguale. Usa questi aggettivi per far capire al medico l'intensità e la natura del tuo malessere.

| Inglese | Italiano |
| :--- | :--- |
| **Sharp pain** | *Dolore acuto / lancinante* |
| **Dull ache** | *Dolore sordo e continuo* |
| **Throbbing** | *Pulsante* |
| **Swollen** | *Gonfio* |
| **Bleeding** | *Sanguinante* |
| **Dizzy** | *Vertiginoso / Con giramenti di testa* |
| **Nauseous / Sick** | *Nauseato* |
| **Weak** | *Debole* |

---

## 4. Frasi Pratiche per Spiegarsi

Metti insieme le parole che hai imparato in queste frasi pronte all'uso, perfette per il bancone della farmacia o la sala visite.

| Inglese | Italiano |
| :--- | :--- |
| **"It hurts when I breathe / swallow."** | *Fa male quando respiro / deglutisco.* |
| **"I have been vomiting since this morning."** | *Vomito da questa mattina.* |
| **"My ankle is very swollen. I can't walk."** | *La mia caviglia è molto gonfia. Non riesco a camminare.* |
| **"I have a terrible rash on my arm."** | *Ho un brutto sfogo cutaneo sul braccio.* |
| **"I feel weak and dizzy."** | *Mi sento debole e mi gira la testa.* |
